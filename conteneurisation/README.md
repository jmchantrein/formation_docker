# Cours « Docker : fondements de la technologie de conteneurisation »

Les diapos du cours Docker, avec les notes de l’orateur, dans `conteneurisation.typ` ; les travaux pratiques dans
`travaux_pratiques.md`. PDF compilé : [`conteneurisation.pdf`](conteneurisation.pdf). Compilation et charte : voir le
[README racine](../README.md) et [`../commun/README.md`](../commun/README.md).

`rejouer.sh` rejoue sur un Debian 13 les commandes dont la sortie est marquée « à rejouer » dans les notes de
l’orateur, et relève les versions : `./rejouer.sh > sorties-conteneurisation.txt 2>&1`.
